Taksim

Spend control and receipts for Claude Code. Taksim keeps ordinary work on Sonnet, steps down instead of cutting off at a budget cap, and shows judged receipts for when Opus was needed. It runs on your machine; no Taksim server exists.

Visit taksim.edgee.tech ↗ Read the docs ↗

How Taksim works

Sonnet by default. Opus when it is needed.

Keep using Claude Code as you do today. Taksim works from what it already writes to disk, prices every session and learns from outcomes which tasks need the stronger model. It never silently changes your model.

01

Install and import

One line installs Taksim for your user. Setup finds your coding agents, then imports and prices the history they already keep.

02

Try cheaper first

When the task fits, a cheaper Claude model goes first. One tier at most: Opus to Sonnet.

03

Step down, never cut off

A budget cap steps requests down to a cheaper Claude model instead of blocking them.

04

Judge

An LLM judge grades finished turns. A verdict counts only when two judges agree and at least one is strong.

05

Learn from corrections

Rejected once, remembered: the next time the same task comes up, the stronger model stays.

06

See the receipts

A local dashboard and weekly report: spend, quota, model mix and what a cheaper model could have saved.

Privacy by architecture

The shape of your work, never the words

Taksim is a local binary with no Taksim account and no Taksim server. It stores client, model, tokens, cost and judge verdicts — never prompts, responses, source code or credentials — and EdgeeTech does not receive your prompts or code. Your agents still talk to their own providers under those providers' terms.

Yuvuno

Your own channel, with the people you love. Yuvuno is a parent-managed home for family photos and kids' videos. Parents share private photos with grandparents and relatives, and keep them completely separate from a public kids' video catalogue. Turkish-first, also available in English.

  • Family space — photos only for the relatives a parent invites, in private Cloudflare R2 storage the service can read (not end-to-end encrypted); location off by default
  • Kids' catalogue — educator review is optional and always labelled; child mode shows reviewed content only
  • No ads, no trackers on family or child pages
  • Invite-only beta — free, five families; photo uploads live, private video uploads not yet

Agent Workstation

A Windows-first desktop hub for specialist AI agents — Career, Blogger and Accountant — that runs on the AI you already pay for: Claude Code, Codex, GitHub Copilot, or a local Ollama model. EdgeeTech never bills you for it. The Accountant specialist checks UK small-company filing deadlines and bookkeeping deterministically; it never files or pays anything. Every write is approval-gated — the model proposes an exact diff, you approve it — backed by evidence citations and a hardened Electron shell. Personal-first and in maintenance mode, with no commercial claim.

The same specialists also install as plugins into Claude Code and Claude Cowork, and the usage ledger imports into Taksim.
